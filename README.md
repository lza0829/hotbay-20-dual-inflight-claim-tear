# 热档片间（Hotbay）

影院素材分区温层：登记 → 冷热迁移 → 保留销毁 → 目录互证。

## 迁移互斥口径（全局唯一，只贯彻这一套）

**读路径最多一把温层锁可重放。** 不采用互斥冻结窗/差异读模型那一套，假第二笔如何收口全局只有一种答案：

- 同分区同时至多一笔占坑（`migrate_open_idx` 部分唯一索引 + `BEGIN IMMEDIATE` 串行写口双保险）；
- 占坑申请与温层改写**同一事务**，锁行目标层即分区现行温层（温层锁死标记 `tier_frozen` 恒为 1）；
- 已有占坑再发起：**整笔挂等候队列**，回执如实告队次与前方占坑单，等候单不触碰温层；回执成功则该单必已按态落账，禁止「成功灯亮却无锁证据」；
- 任何造成双锁的写口**整笔回滚**，禁止只改占坑列表标题；
- 占坑完成/失败回滚后按单号升占坑，目标层与现行相同的等候单整笔拒绝并记拒因（迁移详情页可查）；
- 总览占坑徽章**只能由锁行（`migrate_jobs.status='占坑中'`）∪ 温层锁死标记重放**，旁路读模型一律不参与；占坑数与锁死数不恒等即证据撕裂，总览页亮错。

发起回执、锁行列表、等候读模型、迁移单表、分区温层列、迁移详情拒因页、总览占坑/锁死/等候徽章、并发探针流水同出一库同刷。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/迁移` | 迁移单表全量流水（含拒因备注、等候队次） |
| GET | `/api/迁移/锁行` | 锁行读模型：同分区至多一行，带 `tier_frozen` |
| GET | `/api/迁移/等候` | 等候读模型：队次与前方占坑单可重放 |
| GET | `/api/迁移/{job_id}` | 迁移详情（拒因页）：锁死标记/队次/前方占坑/备注 |
| POST | `/api/迁移` | 发起：无占坑则占坑锁温层，有占坑则整笔入候 |
| POST | `/api/迁移/{job_id}/完成` | 成功完结或失败回滚，同事务升占坑/记拒因 |
| POST | `/api/迁移/并发探针` | 多线程齐发探针，覆盖双锁同改/假第二笔/锁行温层分叉/并发半截 |
| GET | `/api/迁移/探针流水` | 探针运行与逐事件流水（`probe_runs`/`probe_events`） |
| GET | `/api/总览` | 占坑/锁死/等候徽章，全部由锁行重放 |

## 运行

- 前端 http://127.0.0.1:6300
- API http://127.0.0.1:11300
- `docker compose up -d --build`
- 后端闭合校验：`cd backend && python3 tests/migrate_queue_check.py`（服务层并发、HTTP 并发、探针四夹具、读模型同刷、旧毒库收敛）
